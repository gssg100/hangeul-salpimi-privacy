한글살피미 · Chrome 확장 프로그램

개인정보 처리방침

최종 개정: 2026년 10월 13일 · 대상 버전: 0.8.12-preview.1

기본 로컬 맞춤법 검사는 입력한 문장을 외부 서버로 전송하지 않습니다. 사용자가 직접 AI 검사 또는 외부 검사 API를 활성화하는 경우에만 검사 대상 문장 일부가 선택한 외부 서비스로 전송될 수 있습니다.

1. 제공 기능과 입력 내용의 처리

한글살피미는 사용자가 웹페이지에 입력하는 한국어의 맞춤법 및 띄어쓰기 교정 후보를 제시합니다. 교정 버튼을 사용자가 선택하기 전에는 원문을 자동으로 변경하지 않습니다.

짧은 글의 교정 후보는 웹페이지 입력창 근처에 표시되고, 긴 글은 Chrome 사이드 패널에 교정 후보와 오류 주변의 짧은 문맥이 표시될 수 있습니다. 이 패널은 문서 원문 전체를 영구 저장하거나 외부 서버로 전송하는 기능이 아닙니다. 패널을 열었다는 이유만으로 새로운 외부 AI 검사 요청을 보내지 않습니다.

2. 브라우저에 저장하는 정보

  • 검사 설정, 사용자 지정 무시 단어, 검사를 끈 사이트의 호스트명(최대 25개).
  • 사용자가 직접 입력한 API 키와 외부 검사 서버 설정.
  • AI 검사 캐시: 비암호학적 해시 기반 문장 식별키 및 틀린 표현·추천안 등 일부 원문이 포함될 수 있습니다. 최대 350개 항목, 7일 만료를 적용하며 다음 조회·정리 시 만료 항목을 제거할 수 있습니다.
  • 사용자가 직접 추가한 사용자 사전 단어.
  • 사용자가 명시적으로 저장한 미검출 신고 문장과 표현. 자동으로 업로드하지 않습니다.
  • 선택형 복습을 켠 경우, 직접 적용한 로컬 교정 규칙 ID와 횟수. 복습 기록에 문장 원문·사이트 주소·교정 전후 문장은 포함하지 않습니다.

API 키, AI 검사 캐시, 미검출 신고, 사용자 사전 및 복습 이력은 Chrome 확장의 storage.local에 저장합니다. 무시 단어 및 검사 설정, 사이트별 검사 제외 목록 등은 Chrome 동기화 저장소에 보관될 수 있습니다. 동기화 저장소에는 API 키나 신고 문장 원문을 기본적으로 저장하지 않습니다.

3. 선택형 AI·외부 검사 전송

사용자가 별도로 AI/외부 API 기능을 활성화할 때 검사 대상 문장 일부가 다음 중 직접 선택한 API 제공자 또는 사용자가 지정한 검사 서버로 전송될 수 있습니다.

  • Groq
  • Gemini
  • OpenAI
  • 사용자가 직접 입력한 외부 검사 API 주소

전송된 내용의 처리 및 보관에는 선택한 외부 제공자의 약관·개인정보 처리방침이 별도로 적용됩니다. 제공자의 API 호출에 비용이 발생할 수 있습니다. 한글살피미 자체 운영 서버는 현재 사용하지 않습니다.

비밀번호, 결제 카드번호, 인증번호, 계좌번호 등으로 추정되는 입력창을 검사에서 제외하려고 시도하지만, 모든 민감 정보를 완벽하게 분류한다고 보장하지는 않습니다. 민감한 문서를 입력하는 사이트에서는 확장 프로그램 검사 또는 외부 검사를 꺼 주세요.

4. 검사 중단과 전송 제한

전체 검사 또는 특정 사이트 검사를 끄면 해당 사이트의 교정 표시를 중지하고 진행 중인 원격 검사 요청의 취소를 시도합니다. 다만 이미 외부 제공자에 전달된 요청은 회수할 수 없습니다.

조용한 모드는 화면 알림만 줄입니다. 검사나 AI·외부 API 전송 기능 자체를 끄지 않습니다. 외부 전송을 막으려면 설정에서 AI/외부 검사 기능을 비활성화하거나 해당 사이트/전체 검사를 중지해야 합니다.

5. 저장 정보 삭제

  • 설정에서 API 키를 지우고 저장하면 해당 키 값이 삭제됩니다.
  • 저장된 신고 전체 삭제는 확인 후 미검출 신고만 삭제합니다.
  • 저장된 AI 검사 캐시 삭제는 확인 후 해당 캐시만 삭제합니다.
  • 복습 기능을 끄거나 학습 기록 삭제를 사용하면 로컬 복습 이력이 삭제됩니다.

개별 삭제는 다른 설정, 사용자 사전, API 키 등 관련 없는 항목을 함께 삭제하지 않습니다. 이미 사용자가 내보낸 JSON 파일이나 외부 제공자에 전송된 문장은 해당 삭제 기능으로 지울 수 없습니다. 캐시 기능이 켜져 있으면 새 검사 이후 캐시가 다시 생성될 수 있습니다. 확장 제거 시 Chrome이 확장에 연결된 로컬 데이터를 일반적으로 삭제하며, 외부 제공자의 데이터 처리는 별도입니다.

6. 국립국어원 관련 자료

국립국어원 관련 참고 정보는 브라우저 안에서만 교정 분류의 연구 자료로 사용됩니다. 공식 원문 링크는 별도 편집 승인된 경우에만 이용자에게 표시하며, 링크를 사용자가 클릭한 경우에만 공식 HTTPS 사이트가 열립니다. 이때 입력 문장·API 키를 링크 URL에 첨부하지 않습니다. 공식 출처 링크가 공개 승인된 건은 현재 없습니다. 한글살피미는 국립국어원에서 인증하거나 공식 감수한 제품이 아닙니다.

7. 문의 및 변경

서비스 및 개인정보 관련 문의는 Chrome 웹 스토어의 한글살피미 상품 페이지에 표시된 개발자 연락처를 이용해 주세요. 방침 내용이 변경될 경우 이 페이지의 개정일과 내용을 갱신합니다.
